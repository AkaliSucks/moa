# Character Keys

## Universal tiers

Character key tiers are universal Mudae knowledge, not account state:

- Bronze: 1–2 keys
- Silver: 3–5 keys
- Gold: 6–9 keys
- Chaos: 10+ keys

This means MOA must include Chaos mechanics even if no imported harem character currently has ten keys.

## Source and verification policy

The tier boundaries and milestone rewards were transcribed from the Mudae Wiki's Keys page on 2026-07-11. The page is community-maintained, so Mudae's own `$infokeys` output takes precedence whenever the two disagree. The data model records universal mechanics; account imports record actual character key counts separately.

## Important interaction

Most key perks begin affecting later rolls after the key is gained. The key-10 half-power effect is the documented exception: it takes effect immediately on the roll that earns the tenth key.
