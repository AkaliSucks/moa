# MOA

Mudae Optimization Assistant

An offline-first Python application for optimizing every aspect of Mudae progression.

## Goals

- Build optimization engine
- Simulate progression
- Optimize disablelists
- Optimize wishlists
- Simulate kakera economy
- Tower optimizer
- Loot simulator
- Roll optimizer
- Key optimizer
- $oc / $oq / $ot solver support

Built with:

- Python
- uv
- SQLite
- Rich
- Textual
